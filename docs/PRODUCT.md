# TypeAnything · 产品定位与商业模式

> 最后更新：2026-06-06。本文档定义产品长期方向与商业逻辑，作为后续工程决策的依据。

---

## 1. 产品一句话

**TypeAnything 是 Windows 原生 OS 级 AI 改写输入法**：打中文 → 按 Enter → AI 把它改写成你指定的任意语种、风格、口吻 → 在任意 Windows 应用原地落地。

---

## 2. 我们解决什么问题

**真问题不在「会不会说英文 / 认不认识黑话」，在「打字速度 + 切换成本」**。

用户的真实场景：

- 中文程序员想给海外同事写技术 review，硬切英文从 250 字/分钟掉到 60 字/分钟
- 留学生写 essay，想用中英夹杂，但每句都要思考怎么塞英文词
- 金融从业者写邮件，要用「IRR / EXIT / cap table」这种 jargon，没系统训练写不出
- 新手销售 / HR / 客服，要快速 mimic 行业话术，但学不像

**他们都不是「不会写」，而是「写得慢」**。AI 改写就是把「想清楚 → 用拼音飞快敲 → AI 翻译为目标风格」拆成流水线，速度可以重回拼音速度。

---

## 3. 为什么用 IME 形态而不是浏览器插件 / 桌面 App

- **浏览器插件只在 web 内有效**。微信桌面端 / Office / VSCode 等原生应用通通无效
- **桌面 App 要切换窗口**。打断思路 + 多三步操作
- **OS 级 TSF 输入法**：用户在任何应用的输入框打拼音 → 按 Enter → 当场替换。**零切换成本、零额外动作**

这是产品壁垒。竞品（包括 ChatGPT / Claude）都不是 TSF IME 形态。

## 4. 目标用户分层

| Profile | 占比预估 | 行为特征 | 付费意愿 |
|---|---|---|---|
| **A · 普通白领** | 90% | 不知道什么是 API key，装完想直接用，看效果决定续用 | 中（¥10/月级别可接受） |
| **B · 程序员 / 极客** | 5% | 已有 DS / OpenAI 账号，会嫌付订阅贵 | 低（要 BYOK） |
| **C · 隐私党** | 5% | 不信任何云中转，要本地模型 / 自托管 | 极低 |

**v0.9.0 起 Profile A 是主战场**。B 和 C 通过 BYOK 后门保留，但不在 UI 主路径上呈现。

## 5. 商业模式

### 5.1 形态：托管 + 订阅 + BYOK 后门

| 模式 | 用户路径 | 谁付钱 | UI 呈现 |
|---|---|---|---|
| **托管免费试用** | 装完直接用，免登录 | 我们 | 默认 |
| **托管订阅升级** | 跑完免费额度 → 订阅 | 用户付我们 | 模型配置页主推 |
| **BYOK 自托管** | 编辑 `%APPDATA%\Rime\typeanything.schema.yaml` | 用户付 AI 厂商 | 文档隐藏，UI 不暴露 |

### 5.2 定价（试水）

- 免费试用：每月 **5000 tokens**（≈ 50 次中等翻译），按机器码计
- 标准订阅：**¥9.9/月** / ¥99/年（无限调用 + 10x rate limit）
- 团队 / 企业版：暂不做

价格根据 Phase 1 数据动态调整。

### 5.3 成本估算（per user）

- DS API 价格：input $0.14/M、output $0.28/M（汇率按 7.2 算 ≈ ¥1.0/M input、¥2.0/M output）
- 5000 token 月配额 ≈ ¥0.015 成本 / 用户 / 月
- 重度订阅用户 100k token/月 ≈ ¥0.3 成本 / 用户 / 月
- ¥9.9 订阅 margin ≈ 97%（不算服务器 / 域名 / 客服）

### 5.4 收入路径预测（保守）

假设 18 个月跑到 1 万 MAU：
- 1% 付费转化 = 100 付费用户 = ¥990/月 = ¥11880/年
- 5% 付费转化 = 500 付费用户 = ¥4950/月 = ¥59400/年
- 10% 付费转化 = 1000 付费用户 = ¥9900/月 = ¥118800/年

**对单人/双人小团队是合理早期收入；不是 VC 级故事**。

## 6. 关键指标（North Star）

按优先级：

1. **MAU**（月活用户）
2. **触发翻译频次 / 用户 / 周** ←真正衡量价值
3. **免费配额跑满比例** ← 决定有没有付费空间
4. **付费转化率 + 续费率**
5. **NPS / 推荐意愿**
6. **客服 / issue 单 / 用户 / 月**（成本反指标）

---

## 7. 不做什么（保持产品边界）

- **不做手机端**（产品形态决定，IME 在桌面值钱、手机原生输入法已经够强）
- **不做企业 SSO / SAML / 部署版**（小团队负担不起）
- **不卖 prompt 库 / 风格 marketplace**（运营成本高，质量不可控）
- **不做实时打字流式翻译**（用户体验上不如「Enter 后批改」清晰）
- **不做语音输入**（不在核心场景）
- **不做账号体系到底**（v0.9.0 用机器码即可，账号 / 微信登录留给真有付费后再做）

## 8. 风险与对冲

| 风险 | 影响 | 对冲 |
|---|---|---|
| DS 限流 / 涨价 / 政策变化 | 服务质量降级或亏损 | 后端预留多 provider 切换接口（DS / Moonshot / 智谱），客户端无感 |
| 微信 / Office 等大厂改 TSF API | IME 兼容性崩 | 上游 Weasel 社区跟进，我们 fork 同步 |
| 滥用 / 跑额度刷 token | 服务器成本爆 | 后端日额度 + IP 限流 + UA 检查 + 机器码黑名单 |
| 中文 IME 信任问题（用户怀疑偷数据） | 流失 | 客户端永久开源、隐私文档明确、BYOK 后门保留 |
| 单人 / 小团队带宽不够 | 维护塌方 | 早期严控功能边界，issue 优先级严格 |
| 法律 / 合规 / 备案 | 上架受阻 | 域名走个体工商户 / 海外 Cloudflare，避开内地备案 |

## 9. 开源与商业的平衡

- **客户端永久开源**（`A-cat-with-carrots/TypeAnything` MIT + 上游 GPL）
  - 用户能审计代码确认没偷数据 → 维持信任
  - 极客能 fork + contribute → 维持 dogfood 反馈
  - BYOK 后门不删能力（仅删 UI）→ 不背叛 Profile B/C

- **后端闭源**（独立 private repo `typeanything-backend`）
  - 鉴权 / 限流 / 计费算法是商业资产，不必公开
  - Cloudflare Worker + KV，部署 secrets 永不进公开仓库

- **prompts 半开放**
  - `embed_prompts.txt` 随客户端分发即可被解出，不假装是秘密
  - `tools/eval/run_eval.py` 留公开，方便 contributor 改进

## 10. 长期路线（粗略 12-18 个月）

| 时间 | 里程碑 |
|---|---|
| v0.9.0（本月） | 托管模式 default + 免费试用 + 删 BYOK UI |
| v0.9.x | 兑换码 / 推广位 / 付费引导文案打磨 |
| v1.0.0（2-3 月后） | 微信扫码登录 + 支付宝 / 微信支付订阅 |
| v1.1.x | 多 provider 后端调度（DS / Moonshot / 智谱）+ provider quality A/B |
| v1.2.0（半年后） | 团队配额 / 兑换券分销 / 推广联盟 |
| v2.0（一年后） | 真账号体系 / 跨设备同步配置 / 字典 |

每个里程碑都以**数据为依据**决定要不要做，不预设。
